# 🏦 Анализ и прогнозирование оттока клиентов розничного банка (Random Forest)

Система анализа лояльности и оценки рисков ухода клиентов розничного банка. Проект автоматизирует сбор профилей клиентов в базе данных SQLite, выявляет скрытые причины закрытия счетов и строит прогнозы для своевременного удержания вкладчиков.

## 📈 Результаты проекта и бизнес-метрики:
* **Снижение потерь капитала:** Модель помогает банку заранее находить клиентов, которые планируют закрыть счета (исходный уровень оттока в банке составлял 20.40%). Это позволяет вовремя предложить им выгодные условия и сохранить деньги в банке.
* **Главные причины ухода (Важность факторов):** С помощью алгоритма случайного леса математически доказано, что возраст клиента, количество используемых услуг и текущий баланс на счете сильнее всего влияют на решение уйти из банка.
* **Качество работы модели:** Алгоритм обучен с учетом баланса классов (так как лояльных клиентов изначально больше, чем ушедших) и показал высокие результаты на тестовых данных:
  * **Общая точность прогноза (Accuracy):** `82.90%`
  * **Качество разделения классов (ROC-AUC):** `85.86%`

## 🛠️ Стек технологий и инструменты:
* **Работа с данными и SQL:** СУБД SQLite (очистка данных, создание таблиц, написание аналитических запросов с группировкой и расчетом средних значений).
* **Машинное обучение:** Python 3.11, алгоритм случайного леса (`RandomForestClassifier`), библиотека Scikit-Learn (оценка точности, масштабирование и кодирование признаков).
* **Анализ данных и визуализация:** Библиотеки Pandas, NumPy, Seaborn, Matplotlib.
* **Автоматизация отчетности:** Автоматическая генерация понятного 7-страничного отчетного PDF-файла альбомного формата для руководства банка с помощью модуля `PdfPages`.
