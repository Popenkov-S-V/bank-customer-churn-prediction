# 🏦 Прогнозирование оттока клиентов банка (Random Forest)

Предиктивная система анализа лояльности и бинарной классификации рисков оттока пользователей розничного банка. Пайплайн автоматизирует консолидацию профилей клиентов в SQLite, выявляет скрытые поведенческие триггеры закрытия счетов и строит прогнозные оценки для минимизации стоимости удержания портфеля.

---

## 📈 Бизнес-метрики и эффективность
* **Локализация финансовых потерь:** Система позволяет банку проактивно выявлять отток капитала на ранних стадиях, эффективно работая с сегментом клиентов в зоне риска (базовый показатель оттока в портфеле составил `20.40%`).
* **Факторный анализ (Feature Importance):** На основе алгоритма случайного леса математически доказано, что возраст заемщика, уровень расходов и текущий баланс счета выступают главными триггерами выгорания лояльности.
* **Качество ИИ-классификации:** Модель сбалансирована по весам классов для компенсации естественного дисбаланса и зафиксировала следующие показатели на скрытой тест-выборке:
  * **Точность предсказаний (Accuracy):** `82.90%`
  * **Прогностическая сила модели (ROC-AUC):** `85.86%`

---

## 🛠️ Стек технологий и архитектура
* **Данные и SQL:** СУБД SQLite (проектирование реляционных схем, консолидация исторических логов, фильтрация финтех-аномалий).
* **Машинное обучение:** Python 3.11, Ансамблевое обучение (`RandomForestClassifier`), Scikit-Learn (метрики качества, подбор гиперпараметров).
* **Анализ данных и визуализация:** Pandas, NumPy, Seaborn, Matplotlib.
* **BI-отчетность:** Автоматическое программное формирование строгого 7-страничного альбомного PDF-отчета корпоративного формата для топ-менеджмента банка с помощью модуля `matplotlib.backends.backend_pdf.PdfPages`.
